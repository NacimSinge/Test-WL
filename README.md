# Test-WL

## Exécution locale sans OBS

1. Clonez ou téléchargez le dépôt sur votre machine locale.
2. Ouvrez le fichier concerné avec l'outil adéquat (par exemple un interpréteur Python, un éditeur de texte ou l'application prévue).
3. Exécutez le fichier directement depuis votre environnement local pour bénéficier de l'interactivité native (terminal, éditeur, etc.).

## Partage sur Twitch via OBS

1. Ouvrez OBS et ajoutez une nouvelle source de **Capture d'écran**.
2. Sélectionnez la fenêtre ou l'écran où le fichier s'exécute localement.
3. Ajustez la scène OBS puis lancez la diffusion sur Twitch : seule la zone capturée sera partagée avec votre audience.

Ainsi, vous pouvez travailler localement tout en montrant uniquement la portion pertinente sur Twitch.
